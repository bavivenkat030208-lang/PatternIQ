TRANSPARENT BY DESIGN

Make room for discovery.

PatternIQ is an open-source, local-first starting point for making sense of tabular data.

✳

Patterns, not labels

K-Means groups records by similarity after numerical scaling and categorical encoding. Groups are exploratory, and their IDs have no intrinsic meaning.

⌁

Outliers, not accusations

Isolation Forest flags unusual records relative to this dataset. It cannot determine whether a record is a mistake, a rare but valid case, or anything else.

↗

Relationships, not causes

Correlation describes linear association between numeric columns. It does not show that one feature causes another.

⌗

Responsible summaries

Every analysis includes data quality context, feature profiles and a deterministic sample for modeling large files. No made-up model accuracy.

Data stays on this machine: CSV uploads are processed in memory and discarded. Only compact analysis summaries are stored in a local SQLite database.
